# SEO & GEO Agent Skills for Claude Code, Codex, and Cursor

> [!IMPORTANT]
> **This repository has moved. The active toolkit lives in [Aaron Marketing Skills](https://github.com/aaron-he-zhu/aaron-marketing-skills).**
> Its 16 SEO/GEO skills are actively maintained there as part of a 120-skill marketing bundle. This repository's former standalone 20-skill line remains available in the [`v9.9.12` release](https://github.com/aaron-he-zhu/seo-geo-claude-skills/releases/tag/v9.9.12), but it receives no feature updates. Existing installations keep working; install all new versions from the active bundle.

SEO (Search Engine Optimization) and GEO (Generative Engine Optimization) Agent Skills help Claude Code, Codex, Cursor, and other compatible agents research search demand, improve content, audit site quality, and monitor traditional and AI-search visibility.

The active toolkit covers **survey → implement → tune → evaluate** and uses [CORE-EEAT](https://github.com/aaron-he-zhu/core-eeat-content-benchmark) for content quality and [CITE](https://github.com/aaron-he-zhu/cite-domain-rating) for domain authority. Its entrypoint is `/aaron-marketing:seo-geo`.

## Install the active version

| Host | Install |
|------|--------|
| **Claude Code** | `/plugin marketplace add aaron-he-zhu/aaron-marketing-skills` then `/plugin install aaron-marketing@aaron` |
| **Codex · Cursor · OpenCode · Antigravity · Gemini CLI · Copilot CLI · OpenClaw · Hermes · [70+ hosts](https://github.com/vercel-labs/skills#supported-agents)** | `npx skills add aaron-he-zhu/aaron-marketing-skills` |
| **Single skill** | `npx skills add aaron-he-zhu/aaron-marketing-skills -s keyword-research` |
